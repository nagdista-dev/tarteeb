Your day has a natural order defined by prayer, and Tarteeb helps you live it. A daily planner that structures your time around prayer schedules.

## Features

- Prayer-time-aware daily planning
- Automatic schedule generation based on prayer times
- Clean, minimal interface
- Responsive design for mobile and desktop
- Works offline

## Tech Stack

- React 19
- Tailwind CSS 4
- Deployed on Netlify

## Getting Started

```bash
git clone https://github.com/nagdista-dev/tarteeb.git
cd tarteeb
npm install
npm run dev
```

Open `http://localhost:5173`.
